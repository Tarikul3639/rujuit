# SEO Launch Checklist

## Technical SEO
- [ ] Confirm production domain and HTTPS.
- [ ] Ensure important pages return successful status codes.
- [ ] Add unique title tags and meta descriptions.
- [ ] Set canonical URLs.
- [ ] Generate and validate XML sitemap.
- [ ] Configure robots.txt without blocking public pages or assets.
- [ ] Add Open Graph and social sharing metadata.
- [ ] Add accurate Organization / ProfessionalService structured data where applicable.
- [ ] Test mobile usability, page speed, accessibility, and Core Web Vitals.
- [ ] Configure redirects and custom 404 page.

## Content and international reach
- [ ] Define target countries, audience, services, and search intent.
- [ ] Create one strong landing page per core service.
- [ ] Use natural, useful copy; avoid keyword stuffing and unsupported claims.
- [ ] Publish proof: portfolio, case studies, testimonials, team/process details.
- [ ] Decide language and locale strategy before creating translated URL structures.
- [ ] Keep contact details and company information consistent across the website and business profiles.

## Measurement and indexing
- [ ] Verify the domain in Google Search Console.
- [ ] Submit the XML sitemap.
- [ ] Configure analytics and event tracking with appropriate privacy controls.
- [ ] Monitor indexing, search queries, and errors after launch.
