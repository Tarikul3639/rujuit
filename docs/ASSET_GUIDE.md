# Asset Guide

## Brand assets
Keep original, approved identity artwork in `assets/brand`.

- `logos/`: SVG master logo and raster logo variants.
- `banners/`: social and campaign banners.
- `references/`: supplied visual references that help explain or reproduce the brand.

## Website images
Put page-specific imagery in `assets/images`. As the website grows, organize it by purpose, for example:
- `hero/`
- `services/`
- `case-studies/`
- `team/`
- `blog/`

## Usage guidelines
- Prefer the SVG master for logos on the website.
- Preserve original source files; export optimized derivatives for web use rather than overwriting originals.
- Use descriptive, lowercase, hyphen-separated filenames for new files.
- Record source, license, attribution, and intended use for third-party images.
- Avoid embedding text in images when the same content can be real page text.
